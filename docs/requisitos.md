# Requisitos de avaliação do projeto

Como o objetivo dos projetos é praticar os conceitos da linguagem B, os mesmos serão avaliados tomando como base a **extensão e a corretude** do uso dos elementos sintáticos abaixo:

- **Relações e/ou funções**, bem como suas operações (e.g., sobrescrita, subtração e/ou restrição de domínio, subtração e/ou restrição de imagem, inversão, imagem relacional, entre outras);
- **Sequências**, bem como suas operações (e.g., inserção na cabeça e/ou na cauda, concatenação, entre outras);
- **Conjuntos infinitos** de naturais ou números inteiros;
- **Compreensão de conjuntos**;
- **Operações sobre conjuntos** (e.g., pertinência, continência, união, interseção, produto cartesiano, conjuntos das partes, entre outras);
- **Operadores lógicos** (e.g., quantificação universal, quantificação existencial, conjunção, disjunção, implicação, negação lógica, entre outros);
- **Substituições específicas de B** (e.g., atribuição determinística, atribuição não-determinística, `IF`, `CHOICE`, `SELECT`, `CASE`, `ANY`, `LET`, entre outras);
- **Operações com e sem retorno**.
